看到问题后改哪里？

这是你的排障地图，不需要盯着全部 Python 代码猜。
retrieval_empty / distance_gate先看 sources、向量库是否建好、embedding 是否一致、查询是否需要归一化；不要先改 Prompt。
model_abstention距离已通过当前阈值，但模型认为资料不足。人工看 sources：资料真的够，再改回答 Prompt；资料不够，仍是检索问题。
generation_failure / llm_error检索已经完成，检查 DeepSeek Key、余额、模型名、超时和 JSON 返回；不要重建向量库。
security_block系统在模型调用前拦住了疑似提示词注入。检查被召回文档，不要简单关闭安全规则。
Agent 工具结果不对看 tool_calls：工具没选对就改 Agent 路由说明；工具选对但结果错，就查后端 API 或工具函数。
线上都正常但评测下降对比 dev 与 golden；检查最近改过的切块、embedding、阈值、模型和提示词，避免只对少量题调参。
费用只有在 .env 配置当前模型单价后才显示；单价变化时只改配置，不需要改代码。网页主系统的完整访问量需要由入口 Nginx 接入，本页当前统计 AI 服务和其落地页收到的请求。
