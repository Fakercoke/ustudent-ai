# RAG 项目一个月面试复习计划

目标不是背术语，而是能用自己的话完成三件事：讲清流程、解释设计取舍、复盘真实排障。

## 每天的固定练法（20～30 分钟）

1. 口述一个概念，不看答案，限时 60 秒。
2. 回答一道追问题，必须引用项目中的真实数字。
3. 看一次真实代码或接口输出，把概念和代码位置对应起来。
4. 把答得含糊的内容记入“明天优先复习”，不连续重复已经熟练的题。

## 第 1 周：把整条链路讲清楚

- 离线阶段：文档 → 按标题切块 → embedding → Chroma 持久化
- 在线阶段：问题清理 → 查询改写 → 向量检索 → top-3 → 0.75 门槛 → 结构化生成 → 返回来源
- 必须掌握：两个模型的区别、相似度和距离、为什么 AI 只看到三块资料

验收标准：不看文档，能在两分钟内从用户提问一直讲到接口返回。

## 第 2 周：把三个真实排障故事讲熟

- 距离最低却只有 50% 答对率：块太小把答案切断
- 0.40 阈值在标准题完美，却误杀 0.445 的真实口语
- `gradute` 根因实验：三种切块都失败，证明问题来自 embedding 的脆弱性

验收标准：每个故事都按“问题—实验—数据—结论—改进—局限”讲完。

## 第 3 周：工程与评测

- top-k 为什么是 3；切块为什么从固定窗口进化到按标题切
- Chroma 的唯一 ID、重复建库、持久化、余弦距离配置
- 结构化 `can_answer`、`used_fallback`、`degraded`、`sources` 如何诊断
- 开发集、回归验收集、真正盲测集的区别；为什么字符串判分不等于答案正确

验收标准：面试官指出一个失败输出时，能先定位是哪一层，而不是立刻乱调参数。

## 第 4 周：模拟面试

- 每天一次 10 分钟项目介绍，逐渐压缩为 3 分钟和 1 分钟两个版本
- 练习追问：为什么不用 LangChain、为什么不换 embedding、延迟如何处理、如何防幻觉
- 主动承认不足：精确课程代码、改写黑盒、评测题量、索引缺失检测、提示注入风险
- 最后 3 天只复习答错项和真实数字，不再加入大量新概念

## 面试时必须准确说出的当前数字

- 67 个索引块，384 维向量
- top-k = 3，距离阈值 = 0.75，temperature = 0.1
- 22 道开发题 + 8 道回归验收题
- 94 个自动测试全部通过，其中 59 个是 RAG 相关测试
- `gradute`：0.639 → 0.445；中文：0.684 → 0.270
- 块大小 100：距离 0.226 最漂亮，但答对率只有 50%

## 不能说得过满的四句话

- 不说“系统绝对不会编造”，说“通过两层防御降低编造风险，并用评测持续检查”。
- 不说“改写错了也不影响回答”，说“回答仍使用原问题，但错误证据仍可能间接影响答案”。
- 不说“开发集和验收集的差值就是过拟合幅度”，说“差值是泛化风险信号”。
- 不说“LangChain 看不到距离”，说“第一版直接使用底层接口，便于控制变量和观察中间值”。
