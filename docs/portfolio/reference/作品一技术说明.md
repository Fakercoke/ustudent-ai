# 作品一 · RAG 学生手册问答服务（技术参考）

> 这是详细参考资料，平时不需要从头阅读。遇到项目结构、运行方法或关键数字问题时再查。

> 对应课程 Lesson 5–7。这是这个项目的索引页 —— 所有材料的入口。

学生用中文或英文提问，系统从三份手册中检索最相关的三段原文，交给大模型作答，
并返回每段的出处与距离。系统通过距离门槛和结构化资料判断降低无依据回答的风险。

**在线案例页**：https://claude.ai/code/artifact/3f1f958c-e020-4ceb-95c5-2e84a026d71b

## 一分钟跑起来

```bash
# Docker（索引在构建阶段生成，不依赖本地文件）
docker build -t ustudent-ai .
docker run -p 8000:8000 --env-file .env ustudent-ai
# 打开 http://localhost:8000/docs，用 POST /rag-ask

# 或者本地
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env          # 填 LLM_API_KEY
python scripts/build_index.py
pytest                        # 94 passed
uvicorn app.main:app --reload
```

## 三个可讲的结论

**1. 距离低不等于质量好。**
块大小 100 的有答案距离 0.226 是全场最低，答对率却只有 50% ——
小块噪音少所以相似度分数漂亮，但物理上把答案切断了。
距离衡量「找对地方了吗」，答对率衡量「取回的够不够用」。

**2. 在标准题上调出来的阈值，一遇自然问法就失效。**
初版阈值 0.40 在八道正式英文问句上完美，但 `how can i graduate`（0.445）
命中了正确章节却被拒。放宽到 0.50 又会放过 g8（0.520）。
单一阈值无解，改为「宽阈值 + 提示词约束」双层防御。

**3. 拼写错误是模型缺陷，不是切块问题。**
`gradute` 与 `graduate` 相似度 0.549，而无关词 `advising` 是 0.491，只差 0.058。
三种切块方式全部失败。解法在检索之前 —— 查询归一化。

## 已知局限

历史上曾用同一批题调参和报成绩 · 目前评测题量仍小 · 自动判分只是字符串近似检查 ·
查询改写可能偏离原意 · 缺重排序与混合检索 · 跨块信息割裂。

当前已增加 22 道开发集与 8 道验收集。但那 8 道题在项目早期曾参与过阈值分析，
因此面试时应称为“相对独立的回归验收集”，不要宣称它是从未看过的严格盲测集。

详见设计文档最后一节。
